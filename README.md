# Resident Evil // Biohazard Archive

An unofficial Resident Evil fan-site and web-design practice project.

## What is included

- Cinematic survival-horror landing page
- Searchable game incident database
- Character / operative dossiers
- Franchise timeline
- Pathogen archive
- Organizations and factions
- Iconic location archive
- Scanner visual mode
- Responsive mobile navigation
- Scroll reveals and pointer-reactive game cards
- Reduced-motion accessibility support

## Run locally

No dependencies or build tools are required. Open `index.html` directly in a browser, or serve the repository with any simple static-file server.

## Deploy to Vercel

Import this GitHub repository into Vercel. The site is intentionally dependency-free and can be served as a static project from the repository root. No environment variables are required.

## Future media pass

The first version is self-contained so missing remote assets cannot break the layout. A future pass can add franchise artwork, character imagery, game screenshots, ambient video, sound design, interactive maps and dedicated game/character pages. Keep added media in an `assets/` directory or use reliable credited remote sources.
